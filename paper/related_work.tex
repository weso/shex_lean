\section{Related Work} \label{sec:related_work}

Interactive theorem provers such as Lean 4~\cite{Moura2021}, Rocq (formerly Coq)
and Isabelle/HOL allow definitions and proofs to be stated in a formal
language and machine-checked, rather than only reviewed by hand. They have
been used to formalize substantial bodies of mathematics and, increasingly,
the semantics of programming languages and logics used in practice.

\cite{www25} presents the common foundations of SHACL, ShEx and PGSchema.

There have been several approaches to automatically verify large parts of mathematics using automatic theorem provers like Lean, Rocq or Isabelle. 
The application of those techniques in the context of Knowledge Graphs and Semantic web is still not mature compared with other branches of mathematics. Some approaches have already been done like:

\begin{itemize}
    \item Some earlier work was developed using Isabelle/HOL to formalize OWL semantics in \cite{TurnerCarrol07}.
    \item \cite{tantow_et_al:LIPIcs.ITP.2025.36} verifies Datalog using Lean.
\end{itemize}
